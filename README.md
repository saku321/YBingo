# Yearly-Bingos

Web-sovelluksessa käyttäjä voi luoda bingo kortin tulevalle vuodelle ja jakaa sen muille. 
Sivustolle pystyy kirjautumaan Google ja Twitter tileillä. Tili- ja bingo kortin tiedot tallennetaan Mongodb tietokantaan.
Premium tilauksen voi ostaa suoraan Paypal integraation kautta, jolla pystyt customoida kortteja.
